Aplicación de reservas

Una forma sencilla, rápida y organizada de gestionar la Sala Comunitaria.

⭐Principales ventajas

  • Acceso mediante un único enlace para toda la comunidad.
  • No es necesario instalar ninguna aplicación.
  • Diseñada para móviles, tablets y ordenadores.
  • Consulta de disponibilidad en tiempo real.
  • Permite seleccionar varias horas consecutivas.
  • Evita automáticamente las reservas solapadas.
  • Permite establecer un máximo de horas consecutivas.
  • Permite limitar la antelación con la que se puede reservar.
  • Permite establecer una antelación mínima para reservar.
  • Identificación mediante nombre y vivienda.
  • Confirmación automática por correo electrónico.
  • Recordatorio automático antes de la reserva.
  • Permite cancelar una reserva de forma sencilla y segura.
  • Muestra las próximas reservas en la página principal.
  • Permite limitar las reservas por vivienda y mes.
  • Permite establecer los días de la semana disponibles.
  • Permite bloquear fechas y horarios concretos.
  • Mantiene un registro de las operaciones realizadas.
  • Gestión centralizada mediante Google Sheets.

⚙️Opciones de configuración

NOMBRE_SALANombre de la sala.
ZONA_HORARIAZona horaria utilizada.
HORA_APERTURA / HORA_CIERREHorario permitido para reservar.
DURACION_FRANJADuración de cada franja.
MAX_HORAS_CONSECUTIVASMáximo de horas seguidas.
DIAS_ANTELACION_MAXMáximo de días para reservar por adelantado.
HORAS_ANTELACION_MINAntelación mínima para reservar.
PERMITIR_RESERVAS_MISMO_DIAPermite o impide reservas para el mismo día.
NOMBRE_OBLIGATORIOHace obligatorio indicar el nombre.
PISO_OBLIGATORIOHace obligatoria la vivienda.
EMAIL_OBLIGATORIOHace obligatorio el correo.
MAX_RESERVAS_POR_USUARIO_MESLímite mensual por vivienda.
MAX_RESERVAS_POR_DIALímite de reservas por día.
MAX_RESERVAS_MOSTRADASNúmero de próximas reservas visibles.
LUNES → DOMINGOActiva o desactiva cada día de la semana.
CANCELACION_ACTIVAActiva o desactiva la cancelación.
HORAS_MIN_CANCELACIONAntelación mínima para cancelar.
RECORDATORIO_ACTIVOActiva o desactiva los recordatorios.
RECORDATORIO_HORASAntelación del recordatorio.
MOSTRAR_NOMBRE_CALENDARIOControla si se muestra el nombre.
MOSTRAR_PISO_CALENDARIOControla si se muestra la vivienda.
💡 Configuración sencilla: los principales parámetros pueden modificarse directamente desde la hoja CONFIGURACION, sin necesidad de modificar el código.
